# 积值 Valor · 运行零第三方依赖
#
# `python -m butler` 只使用 Python 3.8+ 标准库：
#   urllib        HTTP / JSON-RPC over MCP Streamable-HTTP
#   json          报文与响应解析（含 5 种返回格式的多级兜底）
#   re            Markdown / CSV 解析
#   datetime      到期日与倒计时计算
#   collections   消费与积分统计
#   unicodedata中文显示宽度对齐
#   argparse      CLI 路由
#
# 所以这里没有任何需要安装的包，`pip install -r requirements.txt` 也会直接成功退出。
#
# ⚠️ 另见 tools/README.md：那里的 Node 脚本只用于生成 README 配图，
#    与本项目的运行无关，不装也不影响。
#
